What was set up

    Connect Chrome

    This lets Jarvis work in web pages for you. Three clicks, in order.

    1. Use your work email. If Chrome offers to sign you in to Chrome too, say yes: the Roofr Assist extension then installs itself.
    2. Click Add to Chrome on the page that opens. If Chrome already asked you to turn on "Claude", click Enable instead.
    3. Use the same work email. Then click the puzzle piece at the top right of Chrome and pin Claude.

    The commands you will use

    Three shortcuts cover most days. Everything else is plain English.

    /startFirst thing in a new chat. It reads its notes and tells you where things stand.
    /updateA quick checkpoint in the middle of work.
    /saveWhen you are done. It saves a summary so tomorrow picks up from here.

    The full list is in START-HERE.md in your folder, or type /help.
